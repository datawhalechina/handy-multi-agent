# 0.2 How to Contribute? 💻

As an open-source project, CAMEL's development relies on the power of the community!

* **Code Contributions**: From feature development to bug fixes, from improving documentation to implementing cutting-edge research, we welcome all forms of contributions. Please refer to the [Contribution Guide](https://github.com/camel-ai/camel/blob/master/CONTRIBUTING.md) to quickly submit your code ideas.

* **Documentation Improvements**: If you find documentation that needs improvement or want to add learning examples, feel free to submit an Issue or make direct modifications.

* **Testing Participation**: Help verify the stability of new features and contribute to the framework's reliability!

Let's embark on the journey of learning and exploring multi-agent systems together, building intelligent systems for the future! 🐪✨
