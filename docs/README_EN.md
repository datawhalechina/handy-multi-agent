# Handy Multi Agent

> A practical guide designed for developers who want to deeply understand and practice multi-agent systems

[中文](./README.md) | English

## Project Introduction

**Handy-Multi-Agent** is a practical guide designed for developers who want to deeply understand and practice multi-agent systems. This tutorial is based on the leading multi-agent framework [CAMEL-AI (NeurIPS'2023)](https://arxiv.org/pdf/2303.17760.pdf), starting from basic single Agent development and gradually moving towards building complex Multi-Agent applications.

Project GitHub: https://github.com/datawhalechina/handy-multi-agent
> If you find this project helpful, please give it a ⭐️ Star to help more people discover it!

### Target Audience

This project focuses on hands-on practice and Agent application development, while integrating theoretical components. It is suitable for students interested in multi-agent systems, large language model applications, or artificial intelligence who want to understand and explore LLM applications in multi-agent systems through practice.

Through this project, we aim to help developers:

1. **Understand Fundamentals**: Master the CAMEL framework usage, understand basic Agent concepts, and lay a solid foundation for subsequent learning.
2. **Improve Skills**: Through a series of practical projects involving RAG, Memory, and Multi-Agent, gradually enhance developers' abilities in building and managing intelligent agents.
3. **Apply in Practice**: Encourage developers to apply learned knowledge to solve real-world problems, cultivating practical abilities and innovative thinking.

### Technical Prerequisites

- Suitable for those with **basic Python programming skills**
- Able to **read and understand project source code and theories**
